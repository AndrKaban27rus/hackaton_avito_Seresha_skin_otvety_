# Change: Add onboarding buddy MVP

Implement a reproducible single-scenario prototype for intern onboarding with checklist, source-backed Q&A, and explicit completion action. Use synthetic content and simulated service adapters.

## Why
The case asks for a working prototype demonstrating the path from a question to a result, not a broad onboarding platform.

## Scope
Go API, React UI, PostgreSQL persistence, Redis/Kafka integration points, deterministic assistant adapter, Docker Compose, and CI skeleton.
