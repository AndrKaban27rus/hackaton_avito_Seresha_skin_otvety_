# Первый шаг по инструкции и блокеры

## Зачем

Стажёру нужен конкретный первый шаг с тестовыми инструментами, а не общий совет. Наставник должен узнавать о проблеме сам, но только когда без него работа действительно остановилась.

## Что меняется

- Синтетическая база знаний (имитация Confluence, Grafana и Bitbucket) хранится в PostgreSQL. У каждого ресурса есть задача и нужные допуски. Бэкенд выдаёт ресурс только при наличии допусков.
- Ответ на «С чего начать?» строится из инструкции текущей задачи: для BACK-112 — дашборд Grafana и панель p95, один набор запросов для замеров с кэшем и без, куда приложить результат в Jira. Для BACK-118 — репозиторий Bitbucket и путь к тестам.
- Все ресурсы открываются как тестовые страницы `/demo/<id>` с пометкой «Тестовый ресурс».
- Новая роль — наставник. Запрос о помощи адресуется наставнику из профиля стажёра, а если наставника нет — руководителю.
- Блокер проходит путь: стажёр сообщает о проблеме → бот уточняет причину и предлагает проверку из инструкции → если нужен человек, бот фиксирует блокер и пишет наставнику. Повтор не создаёт дубль. Блокер снимает стажёр или наставник.

## Вне этого изменения

Сводка к 1:1, календарь, подготовка к экватору.
