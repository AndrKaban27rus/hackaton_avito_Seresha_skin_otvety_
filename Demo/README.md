# AI-buddy в Slack

Локальная имитация рабочего пространства Avito в Slack. AI-buddy подбирает стартовые задачи E1 из тестовой Jira. Данные сотрудников, каналы, задачи и доступы вымышлены.

## Запуск

В папке проекта с Python 3.10 или новее выполните:

```powershell
python -B .\app.py
```

Откройте [локальный Slack](http://127.0.0.1:8765) и выберите «AI-buddy» в личных сообщениях. В шапке можно переключаться между тремя стажёрами и руководителем. Для демо используются готовые сессии без ввода пароля.

1. **Алексей Сергеевич Ким · стажёр E1.** Выберите подсказку «Подбери мне стартовую задачу» и нажмите «Отправить». Бот назначит одну из доступных задач и предложит первый шаг. В режиме демо это BACK-112. Затем спросите «С чего начать?».
2. **Елена Игоревна Орлова · стажёр E1.** Отправьте такой же запрос. У Елены есть допуск к тем же стартовым задачам. Можно начать демо с любого стажёра. Второму бот подберёт задачу из оставшихся свободных.
3. **Илья Андреевич Соколов · стажёр E1.** Отправьте такой же запрос. Когда обе задачи уже назначены, бот сообщит, что подходящей задачи нет. У всех троих одинаковые допуски, поэтому порядок профилей можно менять.
4. **Мария Андреевна Волкова · руководитель.** В личных сообщениях от AI-buddy появятся три отдельных отчёта с ФИО, ролью, грейдом и командой.

Перезагрузка восстанавливает переписку, назначение и отчёты. У стажёра кнопка «Сбросить чат» очищает переписку. Следующий вопрос использует действующее назначение из Jira и пустую историю. У руководителя эта кнопка скрывает уже полученные отчёты в личном чате. Новые отчёты появляются по мере подбора задач.

Чтобы повторить демо подбора, нажмите «Начать подбор заново» в профиле стажёра. Кнопка очищает его переписку, снимает тестовое назначение и удаляет его прежние отчёты у руководителя. После новой просьбы о задаче бот заново проверяет Jira и отправляет свежий отчёт.

Назначения, сообщения и отчёты хранятся в SQLite в `instance/slack-demo.sqlite3`. Для чистого прогона задайте `AI_BUDDY_DB` с новым именем файла, например `$env:AI_BUDDY_DB = 'instance/slack-run-2.sqlite3'`, и перезапустите сервер. Порт задаётся через `AI_BUDDY_PORT`. Старый файл `instance/demo.sqlite3` относится к версии с согласованием плана.

## OpenRouter

Задайте ключ в том же PowerShell, из которого запускаете сервер:

```powershell
$slackDemoKey = Read-Host 'Ключ OpenRouter' -AsSecureString
$env:LLM_API_KEY = [System.Net.NetworkCredential]::new('', $slackDemoKey).Password
Remove-Variable slackDemoKey
python -B .\app.py
```

По умолчанию используется `nvidia/nemotron-3.5-super-vl:free`. Другую модель с поддержкой выбора функции можно указать в `LLM_MODEL`. С ключом модель сначала определяет, просит ли стажёр подобрать задачу, уточняет текущую или пишет о чём-то другом. Например, «Есть что-нибудь для меня на сегодня?» запускает подбор, а «С чего начать?» открывает обсуждение текущей задачи. При подборе бэкенд ищет задачи в Jira и передаёт модели для выбора только допущенные варианты. При сбое интерфейс предлагает повторить запрос. Без ключа над полем ввода показывается «Демо · тестовый подбор», просьба распознаётся по простым правилам, а задача выбирается по заданному приоритету.
