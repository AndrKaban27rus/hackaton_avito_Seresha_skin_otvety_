# Подбор стартовой задачи в Slack

Стажёр E1 пишет AI-buddy в личных сообщениях Slack. Бэкенд фильтрует бэклог Jira по грейду, допускам и классификации, модель выбирает подходящую задачу. Бэкенд назначает её и отправляет результат руководителю. При пустом списке стажёр и руководитель получают сообщение об отсутствии задачи. Для демо используются локальные имитации Slack и Jira и синтетические данные.
